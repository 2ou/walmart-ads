# 沃尔玛工作台 · 当前浏览器数据连接

此扩展运行在用户日常使用的 Chrome 中，复用同一浏览器里的领星和供应链登录状态。

- 工作台页面登录后自动完成店铺级握手，不使用配对码。
- 已登录时后台读取并回传业务数据；未登录或登录过期时才把登录标签切到前台。
- 领星 Cookie、请求头不会发送给工作台；只回传库存/WFS 的业务响应 JSON。
- 供应链只回传 Bearer 凭证，并由工作台按当前店铺加密保存。
- 每个桥接令牌只对应一个工作台店铺和一个扩展实例。

开发模式安装：打开 `chrome://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，指向本目录。
