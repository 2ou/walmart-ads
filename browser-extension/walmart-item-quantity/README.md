# Walmart 商品变体查看器

这个独立 Chrome／Edge 插件不需要项目后端。普通查看只读取当前商品页数据；自动模式会在当前标签页逐一导航并请求变体页面。

## 安装

1. 如果收到的是 ZIP，先解压到一个保留的位置。安装目录里应当能直接看到 `manifest.json`。
2. 在 Chrome 地址栏打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`，开启「开发者模式」。
3. 点「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的文件夹（可以是 ZIP 解压后的文件夹，也可以是项目中的 `walmart-item-quantity`）。安装后可从扩展菜单固定到工具栏。
4. 打开 Walmart 美国站商品页，选好颜色和尺码，等页面加载后点击插件。若提示 Item ID 不一致，手动刷新对应变体页，再打开插件。

已经安装旧版时：解压新版到新的文件夹，在扩展管理页移除旧版后加载新版文件夹；或者用新版文件替换旧版所在目录后，在扩展管理页点击该插件的「重新加载」。

## 读数与复制

- 展开「查看本页返回的全部变体」：可搜索颜色、尺码或 ID，按有货/缺货筛选，并复制筛选结果到表格。数量只填写当前 Item 已核实的发货限购值，其他 Item 显示「未取得」；不是整款库存。页面可能不返回全部变体，统计只覆盖已返回的有效 Item ID；重复或无效记录会提示并排除。
- 可选导入历史 CSV（例如 `D:/WorkBuddyData/walmart-orderlimit/variant-order-limit.csv`）。文件必须有 `usItemId`、`orderLimit` 列，可有 `availabilityStatus`。插件按 Item ID 在本地匹配，重复 ID 排除；历史数量与状态单列，采集时间未知时不可当成当前值。CSV 不上传、不保存，关闭弹窗需重新导入。
- 整款复制列顺序：颜色、尺码、Item ID、Product ID、变体状态、价格、币种、当前页单笔下单上限、历史 orderLimit、历史状态。变体状态和价格是页面摘要，不保证与结账或当前发货方式一致；未返回币种时不会猜测。
- 只读取当前地址栏 Item ID 对应的 `SHIPPING` 数据。它显示颜色、尺码、Item ID、发货状态，以及原始 `orderLimit`、`maxOrderQuantity`、`availableQuantity`。
- 两个限购字段一致时显示共同数值，只返回一个有效限购字段时标明来源。冲突、缺失或无法确认时显示「—」，不填成 0。`null` 表示字段存在但值为空；「未返回」表示未读到该字段。
- 「复制本条结果」复制一行制表符分隔数据，可粘贴到表格。列顺序：颜色、尺码、Item ID、单笔可下单件数、发货状态、发货 orderLimit、maxOrderQuantity、availableQuantity、productId、卖家、sellerId、offerId、商品 orderLimit、商品状态、展示价格、币种、读取时间（UTC ISO）、本地时区、履约方式。
- 弹窗中的读取时间是本地读取已有页面数据的时间，不保证是服务器生成数据的时间。卖家、价格、商品和发货两个层级的状态、顶层 orderLimit 分别展示；缺少的值不推测。未提供的币种不会假定为美元。
- 地址支持数字 Item ID 和字母数字 productId，读取时分别与页面中的对应 ID 校验；存在已选变体标记时，还会与变体信息交叉校验。部分单页切换可能暂时不改变地址和原始数据，因此操作后还应人工核对颜色和尺码。
- 这只是当前卖家报价和配送条件下的前台单笔上限，不代表仓库实际库存，也不保证结账时能买到该数量。
- 自动模式须由用户手动启动，每次设定随机等待 1～20 秒后依次在原标签页打开一个 Item。浏览器后台休眠、定时器限制或页面加载可能延长实际间隔；恢复任务的备用闹钟可能在约 30 秒或更久后执行。可暂停、继续、停止并复制已完成结果；异常跳转、读取失败、超时或标签关闭时停止，不尝试绕过验证。进度和结果保存在浏览器扩展本地存储；开始新任务会要求确认覆盖。插件不加购物车、不下单、不上传数据。
- Walmart 的自动访问条款限制系统性或批量采集，随机间隔不保证合规或不会触发限制；使用前请确认自身权限。浏览器重启或扩展禁用时任务可能中断。
