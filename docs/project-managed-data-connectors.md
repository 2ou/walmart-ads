# 项目内置数据连接器

## 目标

沃尔玛工作台直接管理领星与供应链的数据采集，不再依赖浏览器扩展、Node 同步客户端或 Windows 计划任务。业务页面始终读取本地数据库，不会在打开页面时请求第三方系统。

## 数据源

- 领星国内仓库存：`https://czyx.lingxing.com/erp/msupply/warehouseDetail`
- 领星 WFS 货件：`https://czyx.lingxing.com/erp/mmulti/pwShipment`
- 供应链：生产订单、生产中订单、生产发货单和物流信息登记

三类来源独立提交。单个来源同步失败会保留该来源上一版成功快照，不影响其他来源。

## 运行方式

- Spring Boot 主程序负责浏览器采集器的启动和关闭。
- 复用系统安装的 Chrome，但使用按店铺隔离的独立会话，不读取个人 Chrome 配置。
- 每日北京时间 08:00 同步；程序在 08:00 后启动且当天尚未成功时自动补跑。
- 当天成功后不再自动重复，仍可在“自动化准备 → 数据连接”中手动同步。
- PINKSIR 管理员可管理所有店铺，普通店铺账号只能管理自己的连接。

## 首次登录和过期处理

在“数据连接”页面点击“登录领星”或“登录供应链”。项目会打开可见 Chrome 窗口；登录成功并检测到目标接口后自动保存会话、关闭窗口并立即补跑对应数据源。会话过期时工作台显示告警，重新登录即可。

## 安全与审计

- 浏览器 Storage State 和供应链只读凭证使用 AES-256-GCM 加密后按 `workspace_id` 存入数据库。
- 主密钥首次启动自动生成在 `D:/WorkBuddyData/walmart-ads/connector/secrets/connector.key`，不与数据库存放在一起；Windows ACL 只授权程序运行账号。
- 不保存领星 Cookie 或请求头明文。
- 运行日志保留 30 天，记录来源、触发方式、状态、耗时结果和行数。

## 上传兜底

领星国内仓库存和 WFS 货件继续支持页面文件上传。上传成功可立即接管当前数据；下一次项目自动同步成功后切回自动来源。本地目录扫描不参与这两类数据，扫描仅保留退款率。
