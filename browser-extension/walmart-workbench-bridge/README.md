# 沃尔玛工作台 · 当前浏览器数据连接

此扩展运行在用户日常使用的 Chrome 中，复用同一浏览器里的供应链登录状态。

- 工作台页面登录后自动完成店铺级握手，不使用配对码。
- 供应链通过浏览器连接同步；需要登录时，由用户在工作台手动打开相应页面。
- 国内仓库存和 WFS 货件由工作台通过领星 MCP 同步；插件不再访问领星页面，文件上传仍可兜底。
- 供应链只回传 Bearer 凭证，并由工作台按当前店铺加密保存。
- 每个桥接令牌只对应一个工作台店铺和一个扩展实例。

开发模式安装：打开 `chrome://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，指向本目录。
