# 项目内置数据连接器

## 目标

沃尔玛工作台直接管理领星与供应链的数据采集。轻量 Chrome 会话桥只负责复用当前浏览器已有登录状态，不需要 Node 同步客户端、Windows 计划任务或单独启动一套浏览器。业务页面始终读取本地数据库，不会在打开页面时请求第三方系统。

## 数据源

- 领星国内仓库存：`https://czyx.lingxing.com/erp/msupply/warehouseDetail`
- 领星 WFS 货件：`https://czyx.lingxing.com/erp/mmulti/pwShipment`
- 供应链：生产订单、生产中订单、生产发货单和物流信息登记

三类来源独立提交。单个来源同步失败会保留该来源上一版成功快照，不影响其他来源。

## 运行方式

- 工作台页面与扩展自动握手，扩展复用当前 Chrome 的领星和供应链会话。
- 已登录时直接读取；未登录或登录过期时才新开并激活对应系统的登录标签。
- 扩展每小时尝试同步领星库存与 WFS；供应链在每日北京时间 08:00 同步，错过后会在浏览器恢复时补跑。
- 仍可在“自动化准备 → 数据连接”中随时手动同步。
- PINKSIR 管理员可管理所有店铺，普通店铺账号只能管理自己的连接。

## 首次登录和过期处理

工作台和领星/供应链使用同一个 Chrome。打开工作台后会自动识别扩展；点击“登录领星”或“登录供应链”时，扩展优先复用已有标签和会话，只有未登录时才将登录标签切到前台。登录成功后会自动补拉对应数据源。

## 安全与审计

- 每次工作台登录页面发放随机桥接令牌；数据库只保存 SHA-256 摘要，并绑定 `workspace_id` 与扩展实例。
- 供应链只读凭证继续使用 AES-256-GCM 加密后按 `workspace_id` 存入数据库。
- 不保存领星 Cookie 或请求头明文。
- 运行日志保留 30 天，记录来源、触发方式、状态、耗时结果和行数。

## 上传兜底

领星国内仓库存和 WFS 货件继续支持页面文件上传。上传成功可立即接管当前数据；下一次项目自动同步成功后切回自动来源。本地目录扫描不参与这两类数据，扫描仅保留退款率。
