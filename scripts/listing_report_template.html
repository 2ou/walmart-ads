5建议方案

按可直接粘贴的顺序给出；标题 3 选 1，其余为替换件。

① 标题（3 个候选，均含 Brand + 品类 + 人群 + 场景 + 尺码）

规则：首词必须是品牌 PINKSIR；把 Plus Size 与 1X-5X 都写进去（大码人群两种搜法都有人用）；fall 是季节流量入口，Business Casual / Work 是高转化场景词；避免与前缀重复堆词（Walmart 对重复词有降权）。

② Key Features 六条改写（替换现有六条）

改动逻辑：去掉 emoji（Walmart 前台渲染不稳定），改用 [标签] 纯文本；第 1、2 条给材质与尺码（权重最高），第 3 条单独立出「肩扣」这把唯一差异化细节，第 4 条塞场景词（business casual / office / teacher / travel），第 6 条给尺码引导降低退货。

③ 描述（shortDescription）补词要点

  • 首段前 30 词植入头部词：plus size long sleeve tunic blouse / fall business casual top / ribbed knit。
    现开篇为「Comfortable style for workdays and weekends.」——情感开场但零关键词，建议改为「This PINKSIR plus size long sleeve tunic blouse is an easy fall and business casual layer…」。
  • 补 3 个高频场景词：teacher outfits、office、capsule wardrobe（后者在词库中出现 16 次）。
  • 补尺码段：明确「1X–5X 大码专版，覆盖臀线」，并保留现有「请对照 PINKSIR 尺码表下单」的退货抑制话术。
  • 如面料确有再生涤纶或取得 OEKO-TEX，务必写进描述第 2 段（这是竞品唯一的材质级护城河，没有就强调「罗纹针织 + 不起球 + 不厚重」）。
  • 整体保持现有四段式结构，不要推倒重写——现描述已达同类中上水平。
